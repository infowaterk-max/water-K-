1. Factory compile and contract tests;
2. produce the 14 real representative assets;
3. switch each proven asset from `planned` to `ready`;
4. exact-head technical QA;
5. internal Desktop/Tablet/Mobile screenshot review against the accepted reference;
6. set `internalVisualReviewPassed=true` only after the screenshot review;
7. only then expose a Product Owner preview.
