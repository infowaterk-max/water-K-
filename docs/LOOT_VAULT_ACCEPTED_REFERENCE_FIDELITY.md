# Loot Vault — accepted reference fidelity brief

Status: canonical visual target for the current launch-quality rebuild.

Reference identity: `gaming.loot-vault.accepted-reference-2026-09-06`.

## Non-negotiable visual character

Loot Vault is not a generic dark storefront and not a wireframe. It is a warm, cinematic collector/fandom storefront with near-black surfaces, bronze/gold highlights, parchment warmth, deep burgundy/petrol accents and layered light.

The accepted Home reference contains:

1. **Cinematic hero**
   - full-bleed fantasy/sci-fi character or environment artwork;
   - dramatic directional light and atmosphere;
   - large high-contrast headline;
   - primary CTA integrated into the artwork, not floating in an empty panel.

2. **Universe discovery strip**
   - image-led tiles, not text-only buttons;
   - distinct visual identity per universe/category;
   - compact, premium card treatment with hover response.

3. **Limited / Exclusive / Preorder merchandising**
   - real representative product imagery in every visible card;
   - visible state badges;
   - price, favorite and cart actions;
   - no blank grey media, no geometric placeholder artwork.

4. **Collector editorial scene**
   - room/shelf/collection photography or photorealistic generated scene;
   - layered split composition with a strong editorial message;
   - depth, glow, shadow and material richness.

5. **Trust / collector benefits**
   - compact icon cards;
   - visually subordinate to merchandising;
   - consistent bronze/gold accent treatment.

## Product Owner readiness contract

The Product Owner preview stays CLOSED until all of the following are true:

- Home, Catalog and PDP are visually complete on Desktop/Tablet/Mobile;
- at least 14 representative media assets exist across hero, universe/category, product and editorial-scene surfaces;
- no prominent placeholder SVG/geometric art remains;
- no blank product media remains;
- shopper-facing copy is Hungarian except intentional brand names;
- hover/focus states exist on primary cards/CTAs;
- section depth uses image overlays, gradients, shadows or controlled glow where the accepted reference requires it;
- screenshot review has been completed internally against this reference brief;
- the quality manifest is explicitly promoted to `productOwnerReview.ready=true`.

Technical QA green status is necessary but not sufficient for Product Owner preview. A candidate must never be shown as an "Élő előnézet" solely because CI, typecheck, responsive matrix or runtime gates are green.
