# Template Production Brabus Readiness

Template #3 authoring is forbidden until the existing Template Factory authority reports `template3AuthoringReady: true` and the later end-to-end adversarial production rehearsal passes.

This is not a second gate. Brabus production maturity is carried by the existing Generator Readiness → visual-fidelity catalog → Template Factory Quality Gate evidence path.

## Maturity semantics

- **PROVEN** — canonical executable implementation plus executable proof exists.
- **EVOLVE** — useful capability exists, but the Brabus target or current-stack proof is incomplete.
- **RETHINK** — the current approach is structurally unsuitable.
- **NOT_IMPLEMENTED** — no canonical executable implementation exists yet.

Documentation may explain intent but never promotes a capability to PROVEN.

## Current expected gap families

The current Builder already has substantial proven foundations: Guarded Freedom, Normal/Advanced/Expert, hierarchy/Layers, responsive inheritance/reset, reusable presets/blocks/globals, Design Guard, interaction states and undo/redo.

The revalidation intentionally keeps the following visible until hardened: E1–E11/E13 current-stack adversarial revalidation, stronger Publish Readiness and inheritance/visual-diff intelligence, Smart Intent, Smart Auto-Fix, immutable Template Genome, Media Planner/Compiler, anti-clone distinctness, deterministic lineage, Template Type System / Constraint Planner and the higher-level dynamic production compiler.
